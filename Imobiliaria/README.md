Projeto Imobiliária

Sobre o projeto

Projeto desenvolvido durante os estudos de desenvolvimento Front-End pela DevMedia.

A proposta é praticar a criação de uma página web para uma imobiliária, utilizando tecnologias de desenvolvimento web.

Tecnologias utilizadas

HTML5

CSS3

Objetivo do aprendizado

Praticar a estruturação de páginas com HTML, estilização com CSS e organização de arquivos em um projeto Front-End.
